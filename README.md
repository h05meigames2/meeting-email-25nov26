## The line

> We spent an hour in a meeting reading the email out loud, then booked a follow-up to decide what it meant — nobody has actually read it yet.

## How it works

`main.py` is deterministic Python with no network access and no randomness. It writes the single line (140 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

The joke turns on the meeting's own absurdity: an hour spent reading an email aloud to people who could have read it themselves, a follow-up meeting to interpret it — and the punch lands in the last words, because after all that, nobody has actually read it yet. Anyone who has sat through that meeting recognises it instantly.

## Run

```bash
python3 main.py
```

With a custom output directory:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
